# NearLink Logo Generation Prompt for Gemini Nano

## Detailed Prompt (English)

```
Create a modern, professional logo for "NearLink" - a mobile application that connects local service providers (plumbers, electricians, carpenters, etc.) with customers in Pakistan's informal economy using AI technology.

Key Concept:
- The app "links" nearby service providers with customers
- Uses AI agents to match people based on location and needs
- Focuses on quick, local connections in urban Pakistani cities

Design Requirements:
1. Color Scheme: Green & Gold combination
   - Primary Green: #00b140 (fresh, trustworthy, energetic)
   - Primary Gold: #f5a623 (premium, vibrant, eye-catching)
   - Use both colors together for a dynamic, attractive look
2. Style: Modern, minimal, clean with energy (like Careem but more vibrant)
3. Icon should represent:
   - Connection/linking (between people)
   - Location/proximity (nearby/local)
   - Services/tools (plumber, electrician work)
   
Visual Concepts (choose one approach):
- Two points/nodes connecting with a line or curve
- Location pin with connection symbol
- Handshake or connection between service provider and customer
- Tools (wrench/hammer) with location marker
- Network/mesh showing local connections

Typography:
- Font: Modern, bold, sans-serif
- Text: "NearLink" or just "N" for icon
- Should work in both English and Urdu contexts

Style Guidelines:
- Minimalist and scalable (works at 16px to 1024px)
- Flat design, no gradients (simple solid colors)
- Should look good on: white background, mobile app icon, website header
- Professional but approachable
- Should convey trust, speed, and local expertise

Color Palette:
- Primary Green: #00b140
- Primary Gold: #f5a623
- Light Gold: #ffc107
- White: #FFFFFF
- Dark gray: #1a1a1a for text/details
- Use gradient: Green to Gold for modern look

Format:
- Square logo (1:1 ratio) for app icon
- Horizontal version for website/branding
- Should be recognizable even without text

Target Audience:
- Pakistani customers needing home services
- Service providers (mechanics, plumbers, electricians)
- Urban cities like Karachi, Lahore, Islamabad

Inspiration:
- Careem (ride-hailing - similar market and style)
- UrbanClap/Urban Company (home services)
- Thumbtack (local services)

Avoid:
- Complex illustrations or realistic images
- Too many colors (keep it simple)
- Dated or old-fashioned styles
- Corporate or cold appearance
```
