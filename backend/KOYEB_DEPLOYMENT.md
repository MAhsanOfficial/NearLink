## 🚀 Quick Deploy

### **Step 1: Sign Up**

1. Go to: https://www.koyeb.com/
2. Click **"Sign Up Free"**
3. Choose **"Continue with GitHub"**

**No card required!** ✅

---

### **Step 2: Create App**

1. Click **"Create App"**
2. Select **"GitHub"**
3. Choose **"NearLink"** repository
4. Branch: `main`

---

### **Step 3: Configure**

```
Build:
  Type: Dockerfile (or Buildpack)
  
Run Command:
  uvicorn main:app --host 0.0.0.0 --port $PORT

Working Directory:
  backend
```

---

### **Step 4: Environment Variables**

Add same variables as before.

---

### **Step 5: Deploy!**

Click **"Deploy"**

Wait 2-3 minutes.

Your URL:
```
https://nearlink-backend-org.koyeb.app
```
